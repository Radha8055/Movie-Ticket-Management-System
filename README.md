Movie Ticket Management System

A simple Movie Ticket Management System developed using C++, HTML, CSS, and JavaScript. The project allows users to view available movies, select tickets, calculate the total amount, and manage the booking process.

Features

- 🎬 Display available movies
- 🎟️ Select movie tickets
- 🔢 Enter ticket quantity
- 💰 Calculate total ticket cost
- 🧾 Generate booking details
- 💻 Simple and user-friendly interface
- 🔗 C++ program with web-based front-end files

Technologies Used

- C++ – Core programming and ticket management
- HTML – Web page structure
- CSS – Styling and user interface
- JavaScript – User interaction and calculations

Project Files

- "main.cpp" – C++ source code
- "index.html" – Main web page
- "style.css" – Styling and layout
- "script.js" – JavaScript functionality

How to Run

C++ Program

1. Open "main.cpp" in VS Code, Code::Blocks, or another C++ IDE.
2. Compile the program using a C++ compiler.
3. Run the generated program.
4. Follow the instructions displayed on the screen.

Web Interface

1. Open "index.html" in a web browser.
2. Use the interface to view movies and interact with the ticket booking features.
